# 📊 Data Structures

A complete set of teaching materials for a **Data Structures Class and Laboratory** course — built week by week, lab by lab.

This repository holds everything used to run the course: lesson content, diagrams, in-class practice problems, assignments, quizzes, and a growing **Lab Manual**. It is meant for both the instructor (source of truth for what's been taught) and students (revision material after each session).

## 🎯 Learning Philosophy

Every topic in this course follows the same progression:
Concept → Visualization → Operations → Algorithm → Pseudocode → Implementation → Dry Run → Practice Problem → Assignment.

---

## 📖 Topics Covered This Semester

- Introduction to Data Structures & Data Types
- Abstract Data Types (ADTs)
- Classification: Primitive vs. Non-Primitive, Linear vs. Non-Linear
- Arrays
- Linked Lists
- Stacks
- Queues
- Trees
- Graphs
- Algorithm design fundamentals
- Time & Space Complexity (introduced after core structures)

*(Final topic list and depth will follow the official CLOs.)*

## 📝 Assignments, Quizzes & Exams

- **Assignments** — one per major data structure, aligned with CLOs, increasing in difficulty
